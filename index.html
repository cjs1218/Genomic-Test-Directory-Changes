    How it works

    1. Enter the R code, condition or gene the patient would have been tested under. Old and retired codes work too.
    2. Enter the date they were seen. The version of the directory in force on that date is found for you.
    3. See what has changed since: a short answer you can copy into a reply, then the wording, tests and genes, each change dated by the version that brought it in.

    Try an example:

    • R208 Inherited breast and ovarian cancer, seen June 2019
    • R210 Lynch syndrome, seen September 2020
    • R59 Epilepsy, a code that has since been retired
